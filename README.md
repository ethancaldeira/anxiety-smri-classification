# Trait Anxiety Classification from Structural MRI Slices

Binary classification of trait anxiety (STAI-T) from 2D slices of
T1-weighted structural MRI in the GSP, using transfer-learned 2D CNN
backbones (ResNet50, DenseNet121, InceptionV3) with ImageNet or RadImageNet
weights and two-stage fine-tuning. Each subject's slice-level predictions are
averaged into one subject-level prediction.

This repository contains the code for **Chapter 4** and the structural (sMRI)
arms of **Chapter 7** of a thesis on anxiety prediction from MRI:

- **Ch4 (this repo)**: structural MRI, 2D slice CNNs
- Ch5: rs-fMRI with standard atlases ([anxiety-fmri-classification](https://github.com/ethancaldeira/anxiety-fmri-classification))
- Ch6: custom parcellations ([anxiety-fmri-parcellations](https://github.com/ethancaldeira/anxiety-fmri-parcellations);
  models trained in [anxiety-fmri-classification](https://github.com/ethancaldeira/anxiety-fmri-classification))
- Ch7: multimodal sMRI + fMRI late fusion ([anxiety-multimodal-fusion](https://github.com/ethancaldeira/anxiety-multimodal-fusion));
  **the GSP and ABIDE structural arms are trained here** (ABIDE in [`abide/`](abide/README.md))

## Installation

Tested with Python 3.12 on Ubuntu, on an AWS g4dn.2xlarge instance (8 vCPUs,
32 GB RAM, one NVIDIA T4 GPU with 16 GB). CAT12 preprocessing and slice
extraction ran on an AWS c5.4xlarge instance (16 vCPUs), with 8 subjects
processed in parallel.

```bash
git clone https://github.com/ethancaldeira/anxiety-smri-classification.git
cd anxiety-smri-classification
pip install -r requirements.txt
```

`requirements.txt` pins the exact versions used for the thesis results
(TensorFlow 2.20, Keras 3.12). For GPU training, install
`tensorflow[and-cuda]==2.20.0` or provide the CUDA 12 / cuDNN 9 system
libraries; without them TensorFlow runs on the CPU only. CAT12
preprocessing additionally needs the
[CAT12 standalone](https://neuro-jena.github.io/cat/) build (CAT12.9 with
SPM25, MATLAB Runtime R2023b), which does not require a MATLAB licence.

## Data

### GSP

The Brain Genomics Superstruct Project (GSP) data (Holmes et al., 2015) are
available from
[neuroinformatics.harvard.edu/gsp](http://neuroinformatics.harvard.edu/gsp/);
the behavioural measures used here, including the STAI-T scores, are
obtained through the GSP access application and used under the GSP data use
terms. No GSP images, phenotypes or subject lists are distributed here.

| | |
|---|---|
| Cohort | 879 subjects with a T1-weighted scan and a STAI-T score |
| Target | STAI-T ≥ 36 (the cohort median) = 1, STAI-T < 36 = 0 |
| Chapter 4 subset | 200 subjects, stratified on the label (seed 42): 104 high / 96 low |
| Chapter 4 split | 130 / 29 / 41 train / val / test (test: 21 high / 20 low) |
| Chapter 7 (GSP sMRI arm) | the 877-subject anxiety-fmri-classification split, 595 / 106 / 176 |

Expected layout:

```
data/
├── data_split_GSP_seed42.json          # generated by splits/make_gsp_split.py
└── GSP/
    ├── GSP_participants.tsv
    ├── GSP_subject_list_200.txt        # generated by splits/make_gsp_split.py
    └── slices/
        ├── raw/{axial,coronal,sagittal}/<subject>/<subject>_slice_<idx>.png
        └── preprocessed/{axial,coronal,sagittal}/<subject>/<subject>_slice_<idx>.png
```

**Participants file.** `GSP_participants.tsv` is the GSP phenotype table
saved as tab-separated values, one row per subject, with the GSP subject ID
in a column named `participant_id` (`SubNNNN_S1`). The code reads:

| Column | Use |
|---|---|
| `participant_id` | subject ID; matches the slice directory names |
| `STAI_tAnxiety` | STAI-T score; binarised at `STAI_CUTOFF` (default 36) when the data are loaded |
| `Sex` | `F` / `M`; target of the sex-classification check, and `SEX_FILTER` |

**Subset and split.** `splits/make_gsp_split.py` regenerates the
200-subject list and its train/val/test split from the participants file
(see [`splits/README.md`](splits/README.md)):

```bash
python splits/make_gsp_split.py
```

The data loader reads `data/GSP/GSP_subject_list_200.txt` whenever
`USE_GSP_SUBSET=1` (the default) and reuses `data/data_split_GSP_seed42.json`
for every single-split run on the subset, so all configurations are
evaluated on the same 41 test subjects.

### Pretrained weights

ImageNet weights are downloaded automatically by Keras. For the
RadImageNet runs, download the no-top weights from
[RadImageNet](https://github.com/BMEII-AI/RadImageNet) into
`pretrained_weights/radimagenet/` (or set `RADIMAGENET_DIR`):

```
RadImageNet-ResNet50_notop.h5
RadImageNet-DenseNet121_notop.h5
RadImageNet-InceptionV3_notop.h5
```

## Preprocessing

### CAT12

Each T1-weighted volume is segmented with CAT12.9 (standalone, SPM25):
SPM tissue probability map, affine regularisation to the ICBM/MNI template,
medium bias correction, and CAT12's default non-linear registration to MNI
space (geodesic shooting). The output used is the **modulated warped
grey-matter map** (`mwp1`), on CAT12's 1.5 mm template grid
(113 × 137 × 113). No smoothing is applied. All 879 subjects were
preprocessed.

```bash
export CAT12_DIR=/path/to/CAT12.9_R2023b_MCR_Linux
export MCR_DIR=/path/to/MATLAB_Runtime/R2023b   # default: $CAT12_DIR/v232/R2023b
export GSP_RAW_DIR=/path/to/GSP/raw              # <participant_id>_T1w.nii.gz
export GSP_PREPROC_DIR=/path/to/GSP/preprocessed # CAT12 output, one directory per subject
python preprocessing/scripts/pipeline.py --dataset gsp --all --parallel 8
```

`MCR_DIR` is the MATLAB Runtime R2023b passed to CAT12's `run_spm25.sh`
(for example `/usr/local/MATLAB/MATLAB_Runtime/R2023b` for a default Runtime
install). `CAT12_TPM` overrides the tissue probability map (default: SPM's
`TPM.nii` inside the CAT12 bundle). `--subject-list FILE` or `--subjects ID ...`
restrict the run to some subjects.

### Slice extraction

`extract_slices.py` reorients each volume to RAS, so the axis-to-plane
mapping is fixed, and saves the non-empty slices of the chosen plane as
8-bit PNGs, min-max scaled to 0–255 per slice (index range: from the first
non-empty slice up to, not including, the last one, unless `--start` /
`--end` are given). It is run on both the raw T1w volumes and the CAT12
`mwp1` maps:

```bash
for view in axial coronal sagittal; do
  python preprocessing/scripts/extract_slices.py "$GSP_RAW_DIR" data/GSP/slices/raw \
      --axis $view --pattern '*_T1w.nii.gz'
  python preprocessing/scripts/extract_slices.py "$GSP_PREPROC_DIR" data/GSP/slices/preprocessed \
      --axis $view --pattern '*/mri/mwp1*.nii'
done
```

Slice indices are positions in the RAS-reoriented volume: the template grid
for the CAT12 maps and the native acquisition grid for the raw volumes.

**Slice selection** happens when the data are loaded: for each subject, the
40 slices whose indices are closest to the median index of that subject's
saved (non-empty) slices are used. Each slice is resized to 224 × 224 and
replicated across three channels.

## Model and training

- **Model:** backbone (ResNet50, DenseNet121 or InceptionV3; ImageNet or
  RadImageNet weights) → GlobalAveragePooling2D → Dense(256, ReLU) →
  Dropout(0.5) → Dense(1, sigmoid).
- **Input scaling:** with ImageNet weights, each backbone's own Keras
  `preprocess_input`; with RadImageNet weights, pixels scaled to [0, 1].
- **Stage 1:** backbone frozen; the head trains for 10 epochs at a fixed
  learning rate of 1e-4.
- **Stage 2:** all layers trainable for up to 40 epochs at 1e-4, with a
  10-epoch linear warm-up and cosine decay to 1e-7; early stopping on
  validation loss with patience 10.
- **Checkpoint:** a single checkpoint on the lowest validation loss across
  both stages (`best.keras`) is used for testing.
- **Optimisation:** Adam, binary cross-entropy, batch size 16, balanced
  class weights (scikit-learn `balanced`).
- **Augmentation:** a TorchIO pipeline (left-right flip, small affine,
  bias field, gamma, noise) is implemented in `src/mri_augment.py` and
  disabled by default (`USE_AUGMENTATION=0`); all reported runs use no
  augmentation.
- **Evaluation:** accuracy, precision, recall and ROC-AUC at the slice level
  (every test slice) and the subject level (soft vote: the mean of a
  subject's 40 slice probabilities, thresholded at 0.5). Subject-level
  ROC-AUC is the primary metric.
- **Splits:** single-split runs use the fixed 65 / 15 / 20 subject split.
  Five-fold cross-validation uses stratified folds of the 200 subjects
  (seed 42): each fold of 40 subjects is the test set once, and the
  remaining 160 are split into 130 training and 30 validation subjects.
- **Seeds:** subject splits and folds use seed 42; weight initialisation,
  shuffling and dropout use `TRAIN_SEED` (42). GPU kernels are not
  deterministic by default, so a retrained model can differ slightly from
  the reported one; `DETERMINISTIC_OPS=1` makes repeated runs bit-identical
  at roughly five times the training time.

Every setting lives in `src/config.py`. The ones varied across runs can be
set through environment variables:

| Variable | Values | Default |
|---|---|---|
| `EXPERIMENT_TYPE` | `raw`, `preprocessed` (CAT12) | `raw` |
| `VIEW_MODE` | `axial`, `coronal`, `sagittal` | `axial` |
| `BASE_MODEL` | `ResNet50`, `DenseNet121`, `InceptionV3` | `ResNet50` |
| `USE_RADIMAGENET` | `0` (ImageNet), `1` (RadImageNet) | `0` |
| `RADIMAGENET_DIR` | directory of the RadImageNet `.h5` files | `pretrained_weights/radimagenet` |
| `USE_GSP_SUBSET` | `1` (200-subject subset), `0` (all subjects) | `1` |
| `SPLIT_FILE` | split JSON with `train` / `val` / `test` subject lists | `data/data_split_GSP[_<sex>]_seed42.json` |
| `SEX_FILTER` | `M`, `F` (one sex, with its own seed-42 split) | none |
| `STAI_CUTOFF` | integer | `36` |
| `USE_KFOLD`, `N_FOLDS` | `0` / `1`, integer | `0`, `5` |
| `TARGET_OVERRIDE` | participants column used as target, e.g. `Sex` | none |
| `LABEL_PERMUTE`, `PERMUTE_SEED` | subject-level label shuffle | `0`, `1234` |
| `STAGE1_LR` | stage-1 learning rate | `1e-4` |
| `USE_AUGMENTATION` | `0`, `1` | `0` |
| `TRAIN_SEED`, `DETERMINISTIC_OPS` | integer, `0` / `1` | `42`, `0` |
| `EXPERIMENT_NAME` | output directory name | auto |

A single run:

```bash
EXPERIMENT_TYPE=preprocessed VIEW_MODE=axial BASE_MODEL=ResNet50 python src/train.py
```

## Reproducing the Chapter 4 experiments

[`scripts/reproduce_ch4.sh`](scripts/reproduce_ch4.sh) runs every step
below in order (`scripts/reproduce_ch4.sh all`, or name the steps;
`DRY_RUN=1` prints the commands). The individual commands, from the
repository root:

| Experiment | Thesis | Command | Output directory |
|---|---|---|---|
| Pipeline check: sex classification, raw sagittal, ImageNet ResNet50 | Table 4.1 | `EXPERIMENT_NAME=validate_sex EXPERIMENT_TYPE=raw VIEW_MODE=sagittal BASE_MODEL=ResNet50 TARGET_OVERRIDE=Sex python src/train.py` | `validate_sex` |
| Exp 1: raw vs CAT12 × axial / coronal / sagittal, ImageNet ResNet50 | Table 4.2 | `python run_experiments.py exp1` | `exp1_<type>_<view>_ResNet50` |
| Exp 2: ResNet50 / DenseNet121 / InceptionV3 × ImageNet / RadImageNet, preprocessed axial | Tables 4.3, 4.4 | `python run_experiments.py exp2 --type preprocessed --view axial` | `exp2_preprocessed_axial_<weights>_<backbone>` |
| Exp 3: 5-fold cross-validation, ImageNet ResNet50, preprocessed axial | Table 4.5 | `python run_experiments.py exp3 --type preprocessed --view axial --model ResNet50 --weights ImageNet` | `exp3_kfold_preprocessed_axial_ImageNet_ResNet50` |
| Sex-stratified models, raw sagittal, ImageNet ResNet50, single split + 5-fold | Section 4.3.4 | `python run_experiments.py sex_strat` | `strat_{male,female}_single`, `strat_{male,female}` |
| Per-slice analysis | Table 4.6, Figure 4.4 | `python scripts/make_ch4_tables.py`, `python scripts/make_ch4_figures.py` | `results/ch4_tables/` |
| Borderline-subject analysis | Table 4.7, Figure 4.5 | (same two scripts) | `results/ch4_tables/` |

- The **sex-stratified** runs restrict the 200-subject subset to one sex
  (81 male, 119 female). Each sex gets its own stratified seed-42 split
  (test sets of 17 and 25 subjects, written to
  `data/data_split_GSP_{M,F}_seed42.json`) and its own 5-fold
  cross-validation.
- The **per-slice and borderline analyses** use the 41-subject test-set
  predictions of `exp2_preprocessed_axial_ImageNet_ResNet50` (ImageNet
  ResNet50 on preprocessed axial slices, the Exp 3 configuration).
  Table 4.6 reports accuracy, precision, recall and mean predicted
  probability at each slice position (`table_4_6_all_slices.csv` holds
  every position). Table 4.7 splits the test subjects into borderline
  (STAI-T within ±5 of 36) and non-borderline groups.
- `scripts/make_ch4_tables.py` writes all tables to
  `results/ch4_tables/ch4_tables.txt`, each with the result files it was
  computed from; `--results` and `--out` change the input and output
  directories.
- `python run_experiments.py validate` also runs a label-permutation
  control (`validate_permute`), and `python run_experiments.py all` chains
  validation, Exp 1, Exp 2 and Exp 3 with automatic selection of the
  highest-AUC configuration; the thesis runs use the fixed configurations
  in the table above.

A cross-run summary table of any set of runs:

```bash
python src/evaluate.py table 'results/exp*' --out results/_compare/summary.csv
```

## Chapter 7 structural arms

Both arms use the Chapter 4 configuration carried forward (ImageNet
ResNet50, two-stage fine-tuning, 40 axial slices per subject) and write the
usual run directory. [anxiety-multimodal-fusion](https://github.com/ethancaldeira/anxiety-multimodal-fusion)
reads `predictions_slice.csv` (late fusion) and `best.keras` (Grad-CAM)
from `results/<EXPERIMENT_NAME>/` of this repository.

**GSP** — all subjects, CAT12 axial slices, on the
[anxiety-fmri-classification](https://github.com/ethancaldeira/anxiety-fmri-classification)
GSP split (`data/gsp_split.json` in that repository, generated by
`python scripts/make_gsp_inputs.py --participants /path/to/GSP_participants.tsv`
there; 877 subjects, 595 / 106 / 176), so the structural and functional
arms share the same 176 test subjects:

```bash
USE_GSP_SUBSET=0 SPLIT_FILE=../anxiety-fmri-classification/data/gsp_split.json \
EXPERIMENT_TYPE=preprocessed VIEW_MODE=axial BASE_MODEL=ResNet50 \
EXPERIMENT_NAME=ch7_gsp_full_preprocessed_axial_ResNet50 python src/train.py
```

With `SPLIT_FILE` set, subjects that are not listed in the split are not
used, and the run stops with an error if a listed subject has no slices.

**ABIDE I** — ANTs cortical-thickness maps from the Preprocessed
Connectomes Project, autism vs. control, 774 subjects on a fixed
503 / 116 / 155 split shared with the ABIDE fMRI arm. Setup and commands
are in [`abide/README.md`](abide/README.md); the training command is:

```bash
EXPERIMENT_TYPE=raw VIEW_MODE=axial BASE_MODEL=ResNet50 \
EXPERIMENT_NAME=ch7_abide_ants_axial_ResNet50 python -m abide.train
```

`scripts/reproduce_ch4.sh ch7_gsp abide_data ch7_abide` runs both arms
(`FMRI_REPO` points at the anxiety-fmri-classification checkout, default
`../anxiety-fmri-classification`).

## Outputs

Each run writes one directory:

```
results/<EXPERIMENT_NAME>/
├── config.json                  # every Config value used for the run
├── best.keras                   # trained model (lowest validation loss)
├── training_history.json        # per-epoch metrics, best epoch and stage
├── predictions_slice.csv        # subject_id, slice_idx, true, prob, pred
├── metrics_slice.json           # accuracy, precision, recall, ROC-AUC over slices
├── metrics_subject.json         # same, over subjects (mean slice probability, threshold 0.5)
└── plots/
    ├── training_curves.png
    ├── confusion_matrix_{slice,subject}.png
    ├── roc_curve_{slice,subject}.png
    ├── pr_curve_{slice,subject}.png
    ├── slice_importance.png         # per-slice-position AUC
    ├── slice_misclassification.png  # per-slice-position error rate by class
    ├── prob_by_slice_position.png   # mean P(anxiety) by slice position and class
    ├── borderline_analysis.png      # per-subject mean probability ± SD
    └── prob_vs_stai.png             # subject probability vs continuous STAI-T
```

K-fold runs write one `fold_<k>/` directory per fold plus a
`cv_summary.json` (mean ± SD across folds) at the run root.

All metrics and plots are derived from `predictions_slice.csv`. To
regenerate them for an existing run:

```bash
python src/evaluate.py run results/<EXPERIMENT_NAME>
python src/evaluate.py run results/<EXPERIMENT_NAME> --all-folds   # k-fold
```

Some plots and `predictions_slice.csv` contain subject IDs and per-subject
values; keep `results/` private when working with GSP data.
